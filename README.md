# GitHub Copilot Canvas Apps

Small canvas apps for working alongside chats and coding agents in GitHub Copilot.

| App | What it does |
| --- | --- |
| [Thoughts](apps/thoughts/README.md) | Capture, revisit, edit, copy, and complete ideas across chats. |

## Structure

Each app lives in `apps/<app-name>/`, with its source, assets, and exactly one `README.md`. The root README stays a short catalog.

Use the same README sections for every app: **Overview**, **Preview**, **Use in GitHub Copilot**, **Data**, **Develop**, and **Publish**. Keep instructions specific to the app; no separate setup guides or documentation folders.
