# Canvas apps for the GitHub Copilot app

Small productivity apps for developers working in the GitHub Copilot app. They open in canvas panels alongside your chats and help with day-to-day tasks, from capturing ideas to keeping track of session context.

| App | What it does |
| --- | --- |
| [Thoughts](apps/thoughts/README.md) | Save and revisit ideas across chats. |
| [Context Monitor](apps/context-monitor/README.md) | View nested sessions, filter by pins or model, and compare context usage. |
