# GitHub Copilot Canvas Apps

Canvas apps for GitHub Copilot.

| App | What it does |
| --- | --- |
| [Thoughts](apps/thoughts/README.md) | Save and revisit ideas across chats. |

## Structure

Each app lives in `apps/<app-name>/`, with its source, assets, and one `README.md`.

Use these README sections: Overview, Use in GitHub Copilot, Data, Develop, and Publish. Put installation screenshots in the Use section without captions.
